# 跟着做：17 次粘贴操作手册

> 配套文件：`README.md`（目录说明）、`notes.md`（摘要落盘处）、`assembled/`（要粘贴的 17 个文件）
> 全部动作只有一句话：**打开文件 → 替换尖括号占位 → 粘贴 → 等**。

---

1. 确认已经跑过生成脚本：

   cd <purelyprofit-server 根目录>

## 通用动作（每一次都是这 5 下）

1. 打开本次指定的 `.full.md` 文件
2. `Cmd+A` 全选 → `Cmd+C` 复制
3. **检查内容里有没有 `<` `>` 尖括号包起来的占位**，有就换成真内容（每一步都会说明换成什么）

   > 每个占位**上一行**都有一句 `来源：...`，写着该内容从哪个文件、哪个小节取。
   > **那句 `来源：` 是给你看的提示，不用删也不用改**，留在里面不影响 AI 理解。
   > 例如：
   > ```
   > # 上游结论摘要
   > 来源：docs/db-optimization/notes.md →「## S1 容量建模」
   > <S1 摘要>          ← 只替换这一行
   > ```

4. 粘到 AI 对话框，发送，等它输出完
5. 摘要落盘：
   - **IDE Agent**（有文件权限）：自动写入 `notes.md`，你不用管
   - **网页版 AI**（无文件权限）：手动把输出末尾的 `【Sx 摘要】` 复制进 `notes.md` 对应小节

> 不确定用哪个对话窗口？**每次直接新开一个对话**，最保险。

## 出错怎么判断

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| AI 回复「请提供 S1 摘要」 | 忘了替换 `<S1 摘要>` | 补上占位再发一次 |
| AI 在索引审计里提了新增索引 | 越界了 | 回一句「本轮不谈新增索引，删掉这部分」 |
| AI 的摘要写了 40 多行 | 没压缩 | 回一句「摘要压缩到 15 行以内，只留新增结论和硬约束」 |
| `notes.md` 里同一节出现两份摘要 | 用了追加而不是替换 | 手动删掉旧的一份 |
| 第 8~16 次在同一窗口连着做，后面输出变敷衍 | 上下文串味 | 后面几次新开对话重做 |
| 摘要没写进 `notes.md` | 用的是网页版 AI，无文件权限 | 手动复制粘贴进去 |

## 最小可用集（嫌 17 次太多时）

```
01 → 02 → 03 → 04 → 08-module-operations → 08-module-member → 09
```

7 次粘贴，覆盖「容量基线 + 索引结构 + 写热点 + 两个最热模块 + 上线清单」。

**注意**：第 3 次被明令禁止提新增索引，**缺失索引只会在第 8~16 次里出现**，跳过会拿不到任何新增索引建议。剩余模块建议等上线后有了真实慢查询日志再补，反而更准。
