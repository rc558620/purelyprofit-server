## 简介
本文件面向 purelyprofit-server 的环境配置管理，系统性说明如何在开发、测试与生产环境中正确配置与管理各类环境变量，覆盖数据库连接、Redis 缓存、JWT 密钥、腾讯云服务凭据等关键要素。文档同时阐述配置文件结构与优先级、安全存储与轮换策略、配置验证与错误处理机制，以及配置变更的审批流程建议，并提供可直接使用的配置模板与示例，帮助开发者快速搭建本地开发环境。

**更新** 本次更新新增了腾讯云短信服务和COS对象存储服务的完整配置支持，包括Secret ID、SDK App ID、签名名称、模板ID、区域设置、桶名称、CDN域名等参数。

### 配置模块与环境变量映射
- 配置模块负责将环境变量解析为强类型配置对象，支持多环境差异化配置与默认值回退。

- 所有上述配置项均来自环境变量，未设置时采用默认值，确保在不同环境下的一致行为。

### 腾讯云服务配置

#### 腾讯云短信服务（Tencent SMS）
- **用途**：用于注册、登录、找回密码等场景的验证码发送。
- **配置参数**：
  - `TENCENT_SMS_SECRET_ID`：腾讯云 SecretId（访问管理 → API 密钥管理）
  - `TENCENT_SMS_SECRET_KEY`：腾讯云 SecretKey（与 SecretId 配对，严禁泄露）
  - `TENCENT_SMS_SDK_APP_ID`：短信 SDK AppId（短信控制台 → 应用管理 → 应用列表）
  - `TENCENT_SMS_SIGN_NAME`：短信签名（短信控制台 → 签名管理，需审核通过）
  - `TENCENT_SMS_REGISTER_TEMPLATE_ID`：注册验证码模板 ID
  - `TENCENT_SMS_LOGIN_TEMPLATE_ID`：登录验证码模板 ID
  - `TENCENT_SMS_PASSWORD_RESET_TEMPLATE_ID`：找回密码验证码模板 ID
- **降级机制**：未配置凭证时，短信服务自动降级为仅打印日志模式，不影响应用启动。

#### 腾讯云COS对象存储（Tencent COS）
- **用途**：用于头像、商品图等文件上传和存储。
- **配置参数**：
  - `TENCENT_COS_SECRET_ID`：腾讯云 SecretId
  - `TENCENT_COS_SECRET_KEY`：腾讯云 SecretKey
  - `TENCENT_COS_REGION`：COS 存储桶地域（如 ap-shanghai、ap-guangzhou）
  - `TENCENT_COS_BUCKET`：COS 存储桶名称（格式：BucketName-AppId）
  - `TENCENT_COS_CDN_DOMAIN`：CDN 加速域名（可选，配置后返回 CDN URL 而非 COS 原始 URL）
  - `TENCENT_COS_PATH_PREFIX`：上传文件路径前缀（如 'uploads/'，末尾需带 /）
- **功能特性**：
  - 支持图片类型白名单校验（JPEG、PNG、WebP、GIF）
  - 文件大小限制（最大 5MB）
  - 自动生成唯一对象 Key，避免冲突
  - 支持 CDN 域名加速
  - 公共读权限设置，便于前端直接访问

### 配置变更审批流程（建议）
- 提交流程：提交者在分支中更新配置文件与环境变量，附带变更说明与影响评估。
- 审批流程：至少一名维护者审查，确认安全性、兼容性与回滚方案。

- 回滚机制：若发布后出现异常，立即回滚到上一个稳定版本并恢复配置。

## 性能考虑
- 慢请求/慢查询/慢 Redis 记录阈值可通过环境变量灵活调整，建议在生产环境适当提高阈值以减少噪声日志。
- HTTP 请求超时与请求体大小限制需结合业务场景调优，避免过小导致误判或过大造成资源浪费。
- 分页大小的默认与最大值应平衡用户体验与系统负载，防止一次性返回过多数据。
- **新增** 腾讯云服务性能优化：
  - COS 上传文件设置合理的 Cache-Control 头，提升CDN缓存效率
  - 短信服务支持并发发送，但需注意API调用频率限制
  - 文件上传支持断点续传和大文件分片上传（可扩展）

## 故障排除指南
- 启动失败：检查关键环境变量是否完整且格式正确（如端口、数据库 URL、Redis 地址等）。若缺失，配置模块会使用默认值，但可能导致连接失败或行为异常。
- 数据库连接问题：确认数据库 URL 与影子库 URL 是否正确，网络连通性是否正常，权限是否足够。
- Redis 连接问题：确认 Redis 地址、密码与超时配置，检查网络连通性与防火墙规则。
- 认证失败：核对 JWT 密钥是否正确注入，密钥长度与格式是否符合要求。
- 性能异常：根据慢请求/慢查询/慢 Redis 阈值调整日志级别与阈值，定位瓶颈。
- **新增** 腾讯云服务故障排除：
  - 短信服务：检查 SecretId/SecretKey 是否正确，签名是否审核通过，模板ID是否有效
  - COS服务：确认区域和桶名称匹配，检查网络连通性和权限设置
  - 上传失败：验证文件类型是否在白名单内，文件大小是否超过限制
  - CDN访问问题：确认CDN域名配置正确，检查DNS解析和SSL证书

## 结论
本项目通过集中式配置模块统一管理环境变量，并在启动阶段完成验证与注入，确保应用在不同环境下的稳定性与一致性。新增的腾讯云服务配置支持提供了完整的短信通知和文件存储能力。建议在团队内建立严格的配置变更审批流程，配合密钥轮换与最小权限原则，持续提升系统的安全性与可维护性。

### 安全存储与轮换策略
- 密钥与敏感信息必须存储在受控的密钥管理系统或加密的环境中，禁止提交到版本库。
- 建议采用两把钥匙轮换机制：新旧密钥并行一段时间，验证新密钥生效后再停用旧密钥。
- 定期审计与清理不再使用的密钥，缩短密钥生命周期。
- 在 CI/CD 中使用受限的凭据注入，避免在流水线日志中泄露。
- **新增** 腾讯云服务密钥管理：
  - 短信服务密钥：建议使用独立的腾讯云账号，仅授予短信服务最小权限
  - COS服务密钥：建议使用独立的腾讯云账号，仅授予特定桶的读写权限
  - 定期轮换密钥，建议每90天更换一次
  - 监控密钥使用情况，发现异常立即停用

### 配置验证与错误处理流程
```mermaid
flowchart TD
Start(["启动"]) --> LoadEnv["加载环境变量"]
LoadEnv --> ValidateCfg["校验关键配置"]
ValidateCfg --> CfgOK{"配置有效？"}
CfgOK --> |否| LogErr["记录错误并终止启动"]
CfgOK --> |是| InitDB["初始化数据库连接"]
InitDB --> DBOK{"数据库连接成功？"}
DBOK --> |否| LogDBErr["记录数据库错误并终止启动"]
DBOK --> |是| InitRedis["初始化 Redis 连接"]
InitRedis --> RedisOK{"Redis 连接成功？"}
RedisOK --> |否| LogRedisErr["记录 Redis 错误并终止启动"]
RedisOK --> |是| InitTencent["初始化腾讯云服务"]
InitTencent --> TencentOK{"腾讯云服务可用？"}
TencentOK --> |否| LogTencentWarn["记录警告并继续启动"]
TencentOK --> |是| Ready(["应用就绪"])
LogTencentWarn --> Ready
```
