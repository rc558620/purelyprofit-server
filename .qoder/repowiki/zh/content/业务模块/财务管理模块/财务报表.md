## 简介
本文件系统性阐述财务报表功能的设计与实现，覆盖资产负债表、损益表、现金流量表等核心报表的生成机制，明确数据来源、计算逻辑、展示模型与扩展能力（定制、导出、分析、模板配置、权限控制、自动化）。通过代码级的架构图与流程图，帮助开发者与产品人员快速理解"从数据到报表"的全链路。

**更新** 新增upcoming due account跟踪功能，允许企业监控特定日期范围内的应收账款和应付账款，增强财务管理能力。

## 项目结构
财务报表相关代码集中在 `src/purely-profit/finance` 目录，采用按职责分层的模块化组织：
- 控制器层：对外暴露 HTTP 接口，负责参数解析与响应封装
- 服务层：业务编排与领域逻辑，协调查询、聚合与映射
- 领域工具：金额、日期、标签映射等通用工具
- DTO 层：请求/响应的数据契约
- 数据模型：Prisma Schema 定义财务相关实体
- 仪表板集成：与dashboard-home模块集成，提供实时账款监控

## 详细组件分析

### 报表中心（总览）与报表构建
- 输入：周期（如年）、年份、时间范围等查询参数
- 输出：汇总指标（收入、支出、净现金流、记录数、应收应付）+ 现金流明细 + 账款明细
- 关键流程：
  - 聚合计收与支出，计算净现金流与同比变化
  - 统计未结清的应收应付余额
  - 将现金流与账款映射为报表行
  - 集成upcoming due account监控数据

```mermaid
flowchart TD
Start(["进入 getReport"]) --> Parse["解析查询参数<br/>周期/年/范围"]
Parse --> FetchCF["查询现金流记录"]
Parse --> FetchAcc["查询账款记录"]
FetchCF --> Sum["聚合收入/支出/净现金流"]
FetchAcc --> AccSum["聚合应收应付余额"]
AccSum --> Upcoming["查询即将到期账款"]
Upcoming --> Compare["计算同比变化"]
Sum --> Compare
Compare --> BuildRows["构建现金流行/账款行"]
BuildRows --> Merge["合并为报表响应"]
Merge --> End(["返回响应"])
```

### Upcoming Due Account跟踪功能详解
- 功能：监控特定日期范围内即将到期的应收账款和应付账款
- 实现原理：通过buildUpcomingDueAccountWhere查询条件，筛选到期日在[now, now + withinDays)范围内的未结清账款
- 阈值配置：UPCOMING_ACCOUNT_DUE_WITHIN_DAYS = 7天
- 仪表板集成：在dashboard-home模块中实时展示即将到期的账款提醒
- 业务价值：帮助企业提前准备资金，优化现金流管理

**更新** 新增upcoming due account跟踪功能，提供账款到期预警机制。

```mermaid
flowchart TD
Start(["定时查询即将到期账款"]) --> CalcDue["计算到期时间范围<br/>[now, now + withinDays)"]

Query --> FilterDue["过滤到期日在此范围内的账款"]
FilterDue --> Aggregate["聚合统计<br/>总数/总金额/最早到期"]
Aggregate --> Alert["生成仪表板提醒"]
Alert --> Notify["通知相关人员"]
Notify --> End(["完成"])
```

## 性能考虑
- 聚合计算在服务层完成，避免重复扫描数据库
- 使用金额工具进行高精度数值运算，减少浮点误差
- 合理利用索引与范围查询（日期、状态），降低查询成本
- 对大列表分页与排序，避免一次性加载过多数据
- **新增** upcoming due account查询使用专用where条件，提高查询效率

## 故障排查指南
- 参数校验失败：检查 DTO 字段与示例值是否匹配
- 报表为空：确认查询周期/年份/范围是否正确，是否存在数据
- 金额不一致：检查金额工具的加减与四舍五入策略
- 权限拒绝：确认用户角色与资源授权是否满足
- **新增** upcoming due account监控失效：检查UPCOMING_ACCOUNT_DUE_WITHIN_DAYS配置，确认账款dueDate字段是否正确设置

### 报表数据聚合算法与时间维度
- 聚合算法
  - 收入/支出：遍历现金流记录，按方向累加金额
  - 净现金流：收入减去支出，保留合理精度
  - 应收应付：对未结清账款按类型累加剩余金额
  - 同比变化：与上期净现金流比较，计算百分比变化
  - **新增** upcoming due account：根据dueDate字段筛选指定时间范围内的账款
  - 参考路径：[finance-account-report.domain.ts:1-141](file://src/purely-profit/finance/finance-account-report.domain.ts#L1-L141)，[finance-account.query.ts:85-104](file://src/purely-profit/finance/finance-account.query.ts#L85-L104)

- 时间维度
  - 日期格式化：统一输出"YYYY-M-D"标签
  - 周期选择：支持年/月/自定义范围
  - **新增** upcoming due account时间范围：默认7天，可通过withinDays参数调整
  - 参考路径：[finance-date.utils.ts:1-120](file://src/purely-profit/finance/finance-date.utils.ts#L1-L120)，[finance-overview.query.dto.ts:1-120](file://src/purely-profit/finance/dto/finance-overview.query.dto.ts#L1-L120)，[dashboard-home.constants.ts:78-79](file://src/purely-profit/dashboard/dashboard-home/dashboard-home.constants.ts#L78-L79)
