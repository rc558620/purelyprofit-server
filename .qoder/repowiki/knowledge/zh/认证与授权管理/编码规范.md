- 所有涉及密码操作的 DTO（如 RegisterDto, ChangePasswordDto）均包含 confirmPassword 字段，并在 Service 层通过 ensurePasswordConfirmation 工具函数进行一致性校验。
- 短信验证码相关操作（注册、找回密码）均采用“生成验证码->存入Redis->发送短信”的事务性流程，若短信发送失败则立即回滚删除 Redis 中的验证码。
- 控制器方法统一使用 DTO 类作为参数类型，并通过 Swagger 装饰器（@ApiOkResponse, @ApiOperation）定义 API 文档，返回类型严格对应 Response DTO。
- 在登录和注册成功后，若产品范围为 'purely_profit'，会自动触发 syncStaffMemberships 以同步或激活用户的门店员工会员身份。
