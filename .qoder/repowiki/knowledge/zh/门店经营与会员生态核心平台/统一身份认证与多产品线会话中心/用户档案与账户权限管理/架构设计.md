- **分层架构**：采用 Service-Types-DTO 结构，`auth-profile.service.ts` 和 `auth-capability.service.ts` 负责业务编排，`auth-account-lookup.service.ts` 封装底层 Prisma 数据访问。
- **核心依赖**：深度集成 `AccessControlService` 进行权限计算，依赖 `CacheInvalidatorService` 处理实名状态变更后的缓存同步。
- **数据模型**：通过 `auth-profile.types.ts` 定义 `ProfileUserRecord` 和 `ProfileMembershipRecord`，解耦数据库实体与 API 响应结构。
- **能力解析**：`AuthCapabilityService` 聚合门店配额与角色策略，输出前端所需的首页模块可见性（如 `allowedHomeModules`）和功能开关。
