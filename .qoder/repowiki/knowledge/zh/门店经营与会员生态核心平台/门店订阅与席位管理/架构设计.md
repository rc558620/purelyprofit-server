- 采用 NestJS 模块化设计，通过 `SubscriptionsModule` 组织控制器与服务，依赖 `AuthModule` 进行身份鉴权。
- 职责分层清晰：`SubscriptionsController` 处理 HTTP 请求；`SubscriptionsService` 编排核心业务逻辑（如事务处理、缩容校验）；`SubscriptionsAccessService` 专注权限校验（老板/员工）；`SubscriptionsProfileService` 负责数据组装与席位统计。
- 数据访问层通过 `subscriptions.query.ts` 封装 Prisma 查询操作，支持事务客户端注入，确保在 `updateStoreSubscription` 等原子操作中数据的一致性。
- 使用 DTO (`store-subscription-response.dto.ts`, `update-store-subscription.dto.ts`) 定义 API 契约，并结合 Swagger 装饰器生成文档。
