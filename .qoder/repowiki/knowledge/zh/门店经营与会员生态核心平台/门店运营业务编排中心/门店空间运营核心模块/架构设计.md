- **统一入口与门面模式**：`SpacesController`、`SpaceSessionsController` 等作为 API 边界，委托给 `SpacesService`、`SpaceSessionsService` 等门面服务，内部进一步拆解为 Read/Write/State 细粒度服务（如 `SpaceSessionOpenService`、`SpaceSessionCheckoutService`）。
- **跨域状态协同**：通过 `SpaceReservationsStateService` 实现预约与会话的状态联动（如开台履约预约、结账后自动取消匹配预约、根据预约情况回写空间空闲/预留状态）。
- **分布式锁与并发控制**：在结账流程中引入 `SpaceSessionCheckoutLockService` 配合 Redis 实现锁单机制，防止重复结账或会话状态变更冲突。
- **共享校验逻辑**：利用 `.shared.ts` 文件（如 `space-session-open-validation.shared.ts`）沉淀跨服务的业务规则校验，确保开台、续费等操作的数据一致性。
- **外部依赖集成**：通过 `CommerceModule` 进行门店权限隔离，通过 `SalesRecordModule` 完成结账时的销售单自动生成与库存扣减联动。
