- 采用 NestJS 模块化架构，以 `PlatformMembershipModule` 为入口，通过 `forwardRef` 引入认证模块。
- 分层设计清晰：Controller 层（`platform-membership.controller.ts` 等）处理 HTTP 请求与 Swagger 文档；Service 层按领域拆分为核心服务（`PlatformMembershipService`）、读服务（`PlatformMembershipReadService`）、账本服务（`PlatformMembershipLedgerService`）、订单服务（`PlatformMembershipOrderService`）及合伙人服务（`PlatformMembershipPartnerService`）。
- 引入访问控制服务（`PlatformMembershipAccessService`）统一管理会员等级对应的资源配额（如商品数、员工数）和功能开关（如财务、营销）。
- 包含独立的子账号管理子系统（`StoreSubAccount*` 系列服务），处理子账号的槽位分配、角色快照及交接能力。
- 数据持久化通过 Prisma 客户端进行，大量使用 `$transaction` 保证会员状态变更、积分扣除与订单创建的原子性。
- 性能优化方面，读服务广泛集成 Redis 缓存（`RedisService`），并采用“缓存+后台刷新”策略（`getOrLoadRefreshableJson`）以降低数据库压力。
