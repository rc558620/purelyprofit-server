- 采用 NestJS 标准分层架构：`BusinessAnalysisController` 负责 HTTP 入口与权限校验（JWT + RBAC），`BusinessAnalysisService` 编排业务逻辑与缓存策略，`business-analysis.query.ts` 封装 Prisma 原生 SQL 聚合查询。
- 内部通过 `domain` 层（`buildSalesAggregation` 等）处理原始数据聚合，`mapper` 层（`buildBusinessAnalysisResponse`）负责将领域模型转换为前端 DTO，实现计算逻辑与响应结构的解耦。
- 依赖 `CommerceModule` 和 `PlatformMembershipModule` 进行门店权限解析与历史数据范围裁剪，确保子账号只能访问授权范围内的经营数据。
- 引入 Redis 缓存机制（`getOrLoadRefreshableJson`），对高频查询结果进行 120s 缓存并支持后台静默刷新，平衡实时性与数据库负载。
