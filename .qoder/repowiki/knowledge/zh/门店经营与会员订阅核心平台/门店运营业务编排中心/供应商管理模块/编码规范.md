- 读写服务分离：将查询逻辑封装在 `*ReadService`，变更逻辑封装在 `*WriteService`，并通过门面服务 `*Service` 统一导出。
- 统一的权限校验模式：在读写操作中均注入 `CommerceAccessService`，根据用户上下文解析门店 ID 并校验特定权限点（如 `supplier:create`）。
- 响应数据标准化：所有 API 响应均通过 `*ProfileService` 转换为标准的 `ResponseDto`，确保时间戳格式化为毫秒数且敏感字段按需脱敏或省略。
- DTO 校验与转换：使用 `@IsOptional`、`@Transform` 等装饰器处理可选参数和类型转换，确保进入服务层的数据符合业务约束。
