- **分层架构**：采用 Controller-Service-Domain-Query 的分层设计。`members.controller.ts` 负责 HTTP 接口暴露与 Swagger 文档；`members.service.ts` 与 `members-points.service.ts` 处理业务编排；`members.domain.ts` 封装核心数据转换与校验逻辑；`members-read.query.ts` 与 `members-write.query.ts` 负责底层数据库交互。
- **权限控制**：通过 `MembersAccessService` 实现基于门店（Store）的数据隔离，确保用户仅能操作其权限范围内的会员数据。
- **数据访问**：使用 Prisma ORM 的 `$queryRaw` 执行原生 SQL，以支持复杂的聚合查询、分页统计及高性能的批量写入。
- **模块化设计**：将积分（Points）与纯利豆（Beans）的逻辑抽象为通用的 `members-points.shared.ts` 配置化服务，减少代码重复。
