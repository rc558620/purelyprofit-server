- DTO 类统一使用 `ApiProperty` 装饰器定义 Swagger 元数据，并配合 `class-validator` 进行字段类型与格式校验。
- 数据库查询逻辑按读写职责分离，分别存放在 `*-read.query.ts` 和 `*-write.query.ts` 文件中，并通过 `members.query.ts` 统一导出。
- 涉及多步数据库操作的业务（如创建会员同时初始化充值记录）均使用 `prisma.$transaction` 保证事务一致性。
- 所有对外暴露的 API 接口均强制要求 JWT 认证（`JwtAuthGuard`）并配合自定义的 `RequirePermissions` 装饰器进行细粒度权限校验。
