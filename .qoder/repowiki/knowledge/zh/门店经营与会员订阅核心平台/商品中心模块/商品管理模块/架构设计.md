- 采用 NestJS 标准分层架构，通过 `ProductsModule` 组织依赖，引入 `PrismaModule` 进行数据持久化，并依赖 `CommerceModule` 和 `PlatformMembershipModule` 实现门店权限与配额校验。
- 遵循 Controller-Service-Domain-Query 的职责分离：`ProductsController` 处理 HTTP 请求与 Swagger 文档；`ProductsService` 编排业务逻辑与事务边界；`products.domain.ts` 封装商品编号生成与分类唯一性保障等核心领域规则；`products.query.ts` 集中管理 Prisma 查询构造与数据映射。
- 使用 DTO (`dto/product.dto.ts`) 定义接口契约与校验规则，通过 Mapper (`products.mapper.ts`) 完成数据库实体到响应 DTO 的转换，确保内部领域模型与外部 API 表现层解耦。
