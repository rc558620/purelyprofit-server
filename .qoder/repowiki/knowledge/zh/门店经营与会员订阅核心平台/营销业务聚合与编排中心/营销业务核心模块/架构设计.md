- 采用门面模式（Facade）：`MarketingFacadeService` 作为统一入口，聚合 `Overview`、`Customers`、`Transactions` 等子域门面服务。
- 分层架构：Controller 层处理 HTTP 请求，Facade 层协调业务逻辑，Shared Service 层（`MarketingSharedService`）封装通用的权限校验（`MarketingAccessService`）与数据查询（Prisma）。
- 领域模型隔离：通过 `marketing.types.ts` 定义内部行记录类型，`marketing.mapper.ts` 负责将数据库行映射为 DTO，实现存储层与 API 层的解耦。
- 模块化组织：`MarketingModule` 统一管理依赖注入，导出 `MarketingOverviewService` 供外部模块复用。
