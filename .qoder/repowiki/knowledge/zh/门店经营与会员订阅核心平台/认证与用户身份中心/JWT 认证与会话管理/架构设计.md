- **核心服务层**：`AuthAuthenticationService` 编排业务流程（注册/登录/改密），依赖 `AuthSessionService` 处理令牌签发与失效。
- **策略与守卫**：`JwtStrategy` 负责解析 Token 并校验 Redis 中的 `sessionVersion` 以实现全局登出；`guards/jwt-auth.guard.ts` 提供针对不同产品线（Profit/Club/Pulse）的 Scope 隔离守卫。
- **基础设施支撑**：通过 `auth.utils.ts` 统一管理虚拟邮箱生成与 Redis Key 构建，利用 `@nestjs/passport` 集成 JWT 验证流程。
