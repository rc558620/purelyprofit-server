- 采用 Redis 递增版本号（sessionVersion）机制，在 Token Payload 中携带版本信息，校验时对比 Redis 实时值以支持单用户多端强制下线。
- 通过特定前缀的虚拟邮箱（如 `profit_phone_`）将手机号或自定义账号映射为系统内部唯一的 Email 标识，以兼容 Prisma User 模型。
- 在 `JwtStrategy.validate` 中使用原生 SQL (`$queryRaw`) 联表查询员工与子账号权限，并在表结构缺失时主动抛出异常以防止权限降级。
- 所有涉及密码变更的操作（修改/重置）均会调用 `bumpTokenVersion` 递增 Redis 版本，确保旧令牌立即失效。
