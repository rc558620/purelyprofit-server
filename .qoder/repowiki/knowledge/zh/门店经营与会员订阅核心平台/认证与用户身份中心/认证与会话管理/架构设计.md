- 核心服务层：`AuthAuthenticationService` 编排注册、登录及密码变更流程，依赖 `AuthAccountService`、`AuthPasswordService`、`AuthCodeService` 和 `AuthSessionService`。
- 会话控制：`AuthSessionService` 负责签发包含 `sessionVersion` 的 JWT，并通过 Redis 维护版本号以实现多端踢出或强制登出。
- 鉴权策略：`JwtStrategy` 扩展自 `PassportStrategy`，在验证 JWT 签名后，同步校验 Redis 中的会话版本、用户封禁状态及门店成员权限上下文。
- 防护边界：`JwtAuthGuard` 作为 NestJS 守卫拦截受保护路由，触发 Passport 鉴权流程。
- 工具支撑：`auth.utils.ts` 提供统一的账号标识构建、验证码生成及 Redis Key 前缀管理，确保跨模块的一致性。
