- **分层架构**：采用 Facade 模式，`AuthAccountService` 作为统一入口协调 `AuthAccountLookupService`（负责 Prisma 数据检索与账号同步）和 `AuthAccountMembershipService`（负责 Redis 封禁校验、席位激活及原始 SQL 查询）。
- **能力计算解耦**：`AuthProfileService` 负责组装基础资料与当前门店上下文，而复杂的首页模块可见性及子账号配额逻辑委托给 `AuthCapabilityService`，后者进一步调用跨域的 `SubjectCapabilityService` 和 `PlatformMembershipAccessService`。
- **类型契约**：通过 `auth-profile.types.ts` 和 `auth-account.types.ts` 定义内部记录结构，配合 Swagger DTO 实现 API 响应标准化。
