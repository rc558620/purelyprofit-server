- 入口控制器：`auth.controller.ts` 定义 RESTful 路由，通过 `@UseGuards(JwtAuthGuard)` 保护受保护资源，并委托给 `AuthService` 处理业务。
- 依赖注入模块：`auth.module.ts` 整合 `PassportModule` 与动态配置的 `JwtModule`，导出 `JwtAuthGuard` 供其他模块复用，并通过 `forwardRef` 处理与会员模块的循环依赖。
- 上下文提取装饰器：提供 `@CurrentUser`、`@RequestId`、`@RequestAuditContext` 等自定义参数装饰器，从执行上下文中安全提取用户身份、追踪 ID 及审计信息（IP、UA）。
- 数据传输对象（DTO）：`dto/` 目录下集中管理输入输出模型，利用 `class-validator` 进行字段校验，并通过 `@nestjs/swagger` 注解生成 API 文档。
