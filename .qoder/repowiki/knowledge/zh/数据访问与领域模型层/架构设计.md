- **服务封装**：通过 `PrismaService` 继承 `PrismaClient`，利用 NestJS 生命周期钩子（`OnModuleInit/Destroy`）管理数据库连接的建立与断开。
- **全局注入**：`PrismaModule` 使用 `@Global()` 装饰器，使 `PrismaService` 在整个应用中无需重复导入即可直接注入。
- **适配器模式**：使用 `@prisma/adapter-pg` 配合原生 `pg` 连接池，替代默认的 HTTP 引擎，优化长连接性能。
- **领域化 Schema**：主入口 `schema.prisma` 仅保留基础配置，核心业务模型按领域（财务、会员、运营等）拆分至 `prisma/purely-profit` 子目录下的独立 `.prisma` 文件中，实现逻辑解耦。
- **可观测性集成**：在构造函数中订阅 `query` 事件，根据配置动态开启慢查询日志记录（`console.warn`）及 SQL 指标上报（`recordSqlQuery`）。
