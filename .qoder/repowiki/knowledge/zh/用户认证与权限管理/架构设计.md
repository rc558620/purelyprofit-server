- 采用 NestJS 模块化架构，通过 `AuthModule` 组织依赖，导出 `JwtAuthGuard` 供全局使用。
- 控制器层 (`AuthController`) 负责 API 路由与 DTO 校验，委托给门面服务 `AuthService`。
- 业务逻辑分层细化：`AuthAuthenticationService` 处理核心认证流程，`AuthPasswordService` 负责密码哈希与校验，`AuthCodeService` 管理 Redis 验证码，`AuthProfileService` 处理用户资料与实名认证。
- 安全机制基于 `PassportModule` 与 `JwtStrategy`，在 Token 验证阶段通过原始 SQL 查询加载用户门店成员身份（Staff/Employee/SubAccount），并结合 Redis 实现会话版本控制（Session Versioning）以支持强制登出。
